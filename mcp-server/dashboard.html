🚀 Quick Start

Comandos para iniciar o servidor:

1. Instalar e compilar

cd mcp-server npm install npm run build

2. Iniciar servidor

npm start

3. Testar ferramentas

echo '{"jsonrpc":"2.0","method":"tools/list","id":1}' | node dist/server.js
