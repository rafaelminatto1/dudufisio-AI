## 🎨 Design e UX

### Pontos Fortes do Design

#### 1. **Layout Clean e Moderno** ⭐⭐⭐⭐⭐
- Sidebar escura (#1A4D4D - verde escuro) com ícones minimalistas
- Fundo branco limpo no conteúdo principal
- Cards com bordas coloridas para diferentes seções
- Espaçamento generoso entre elementos

#### 2. **Sistema de Cores**
- **Verde principal:** #1A4D4D (sidebar)
- **Verde secundário:** #2DD4BF (botões e destaques)
- **Cores de status:**
  - Vermelho: Aniversários
  - Verde claro: Confirmados
  - Azul: Agendamentos
  - Amarelo: Avisos
  - Roxo: Outros eventos

#### 3. **Tipografia**
- Fonte moderna e legível
- Hierarquia clara (títulos grandes, subtítulos médios)
- Boa legibilidade em todos os tamanhos

#### 4. **Navegação**
- Sidebar fixa à esquerda
- Ícones intuitivos com labels
- Menu de usuário no topo da sidebar
- Breadcrumbs claros

## 📝 Formulário de Cadastro de Paciente

### Opções de Cadastro

1. **Presencial** - Cadastrar dados com paciente presente
2. **Remoto** - Enviar link para paciente preencher online

### Campos do Formulário

#### Informações Básicas
- [ ] Foto do paciente (max 2MB)
- [ ] Status (dropdown: "Em tratamento", etc.)
- [ ] Cadastrar identificador (opcional)
- [ ] Resumo do diagnóstico (texto livre)

#### Dados Pessoais
- [ ] Nome completo (com autocomplete)
- [ ] Apelido
- [ ] ✅ **Substituir nome pelo apelido** (toggle interessante)
- [ ] Pessoa estrangeira (toggle)
- [ ] CPF (formato: 000.000.000-00)
- [ ] Estado civil (dropdown)
- [ ] Profissão
- [ ] Sexo biológico (dropdown)
- [ ] Gênero (dropdown)
- [ ] Cidade de nascimento
- [ ] Escolaridade (dropdown)
- [ ] Data de nascimento (date picker)
- [ ] Tags (campo de tags)

#### Como me conheceu?
- [ ] Tipo de indicação (dropdown)
- [ ] Indicação de Profissional da Saúde
- [ ] Botão: "Adicionar profissional da saúde"

#### Contato
- [ ] Telefone de contato
- [ ] E-mail
- [ ] Botão: "Adicionar contato" (múltiplos contatos)

#### Convênio
- [ ] Informações de convênio

#### Endereço
- [ ] CEP
- [ ] Rua/Avenida
- [ ] Número
- [ ] Sem número (checkbox)
- [ ] Complemento (opcional)
- [ ] Bairro
- [ ] Cidade
- [ ] Estado (UF)
- [ ] Botão: "Adicionar endereço comercial"

### Funcionalidades Notáveis

1. **Cadastro Remoto** ⭐
   - Paciente preenche formulário online
   - Link enviado por WhatsApp/E-mail
   - Reduz trabalho administrativo

2. **Substituir Nome por Apelido**
   - Toggle para usar apelido em todo o sistema
   - Personalização da experiência

3. **Múltiplos Contatos**
   - Adicionar vários telefones/e-mails
   - Útil para contatos de emergência

4. **Endereço Comercial Adicional**
   - Pacientes podem ter 2 endereços
   - Residencial e comercial

5. **Indicação de Profissionais**
   - Rastrear origem dos pacientes
   - Networking entre profissionais

6. **Tags Personalizadas**
   - Categorizar pacientes livremente
   - Facilita busca e filtros

## 💪 Biblioteca de Exercícios

### Visão Geral
- **15.000+ exercícios disponíveis** (conforme marketing)
- Interface em grid com cards visuais
- Vídeos demonstrativos em cada exercício
- Sistema de favoritos (estrela)

### Layout dos Cards
- **Thumbnail verde-água** (cor da marca)
- **2 fotos por exercício** (início e fim do movimento)
- **Nome do exercício** abaixo das fotos
- **Ícone de favorito** (estrela) no canto

### Funcionalidades

#### 1. Busca e Filtros
- Campo de pesquisa
- Botão "Favoritos" (filtro rápido)
- Botão "Filtros" (filtros avançados)

- Abaixamento do lábio inferior
- Abdominais (múltiplas variações)

  - Bola
  - Halter
  - Elástico
  - Anel de pilates
  - Fita de suspensão
  - Reformer
  - Cadillac
  - Wall ball
  - Kettlebell

#### 3. Organização
- Nomes descritivos e específicos
- Variações numeradas (I, II, III)
- Indicação de equipamento no nome
- Fácil identificação visual
