
# Protocolo: Mobilidade e Estabilização Pós-Artrodese Lombar

**Resumo:** Programa que respeita o tempo de consolidação óssea, com foco inicial na mobilidade de quadril e torácica para compensar a rigidez lombar, seguido de um trabalho intenso de fortalecimento do core profundo para criar um "espartilho muscular" protetor.
