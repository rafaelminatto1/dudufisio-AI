
# CHECKLIST: SUA CASA ESTÁ SEGURA?

Pequenas mudanças em casa podem fazer uma grande diferença na prevenção de quedas. Verifique os itens abaixo:

**Pisos e Passagens:**
*   [ ] Remover todos os tapetes soltos ou prendê-los firmemente ao chão.
*   [ ] Manter os caminhos livres de objetos (fios, sapatos, caixas).
*   [ ] Assegurar que não haja desníveis ou tacos soltos no piso.

**Iluminação:**
*   [ ] Ter boa iluminação em todos os cômodos, especialmente no caminho entre o quarto e o banheiro.
*   [ ] Usar luzes noturnas (abajur ou luz de tomada) para facilitar a locomoção à noite.

**Banheiro:**
*   [ ] Instalar barras de apoio dentro do box e ao lado do vaso sanitário.
*   [ ] Usar um tapete de borracha antiderrapante dentro do box.
*   [ ] Considerar o uso de uma cadeira de banho para mais segurança.

**Quarto e Sala:**
*   [ ] Ter um telefone de fácil acesso.
*   [ ] Organizar móveis para criar caminhos largos e desobstruídos.
*   [ ] Usar sapatos firmes e com sola de borracha, mesmo dentro de casa. Evite chinelos soltos.
