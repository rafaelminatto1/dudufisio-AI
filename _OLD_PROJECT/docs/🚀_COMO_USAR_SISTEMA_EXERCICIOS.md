# 🚀 GUIA RÁPIDO - Sistema de Exercícios

## ⚡ Começar Agora em 3 Passos

### 1️⃣ Acessar o Sistema
```
http://localhost:5176/exercises
```

### 2️⃣ Criar seu Primeiro Exercício
1. Clique no botão **"Novo Exercício"** (canto superior direito)
2. Preencha o formulário:
   - **Tab Básico:**
     - Nome: "Agachamento Livre"
     - Descrição: "Exercício fundamental para fortalecimento de membros inferiores"
     - Categoria: Selecione "Fortalecimento"
     - Dificuldade: "Iniciante"
     - Equipamentos: Marque "Nenhum"
     - Músculos Alvo: Adicione "Quadríceps" e "Glúteos"
   
   - **Tab Instruções:**
     - Instruções: Adicione passos detalhados
     - Dicas: Adicione dicas de execução
   
   - **Tab Parâmetros:**
     - Séries: 3
     - Repetições: 15
     - Descanso: 60 segundos
   
3. Clique em **"Salvar Exercício"**

### 3️⃣ Gerenciar seus Exercícios
- **Buscar:** Digite no campo de busca
- **Filtrar:** Use os dropdowns de Categoria e Dificuldade
- **Editar:** Clique no menu (...) > Editar
- **Duplicar:** Clique no menu (...) > Duplicar
- **Excluir:** Clique no menu (...) > Excluir > Confirmar

## 📋 Campos Principais

### Informações Básicas (Obrigatórios)
- ✅ Nome do exercício
- ✅ Descrição (mínimo 10 caracteres)
- ✅ Categoria
- ✅ Dificuldade
- ✅ Equipamentos (pelo menos 1)
- ✅ Músculos Alvo (pelo menos 1)
- ✅ Instruções (pelo menos 1)

### Informações Opcionais
- Músculos Secundários
- Dicas de Execução
- Variações do Exercício
- Contraindicações
- Parâmetros (séries, reps, peso, etc.)
- URLs de Mídia (imagem/vídeo)
- Tags e Palavras-chave
- Partes do Corpo
- Nível de Progressão

## 🔍 Dicas de Uso

### ✨ Atalhos do Teclado
- **Enter** nos campos de arrays = Adicionar item
- **Tab** = Navegar entre campos

### 📝 Boas Práticas
1. **Nome Claro:** Use nomes descritivos
2. **Instruções Detalhadas:** Mínimo 3 passos
3. **Adicione Dicas:** Erros comuns e correções
4. **Use Tags:** Facilita a busca depois
5. **Contraindicações:** Sempre liste quando aplicável

### 🎨 Organização
- Use **categorias** para organizar por tipo
- Use **dificuldade** para progressão
- Use **tags** para agrupamentos (#iniciante, #joelho, etc.)
- Use **equipamentos** para filtrar por disponibilidade

## 🆘 Problemas Comuns

### Erro: "Categoria é obrigatória"
✅ **Solução:** Selecione uma categoria no dropdown

### Erro: "Instruções deve ter pelo menos 1 item"
✅ **Solução:** Adicione pelo menos uma instrução

### Erro: "Nome deve ter no máximo 200 caracteres"
✅ **Solução:** Encurte o nome do exercício

### Não consigo adicionar músculos
✅ **Solução:** Digite o nome e pressione Enter ou clique no botão +

### Exercício não está salvando
✅ **Solução:** 
1. Verifique se todos os campos obrigatórios estão preenchidos
2. Olhe as mensagens de erro em vermelho
3. Corrija e tente novamente
