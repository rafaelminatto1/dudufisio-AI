## 🚀 Como Funciona a Parceria

### 1. Recebimento de Clientes
```
Fisioterapeuta → Encaminha paciente
             → Você recebe notificação
             → Cliente aparece em sua lista
             → Você agenda primeira sessão
```

### 2. Atendimento
```
Sessão → Avaliar cliente
      → Prescrever exercícios
      → Registrar evolução
      → Reportar ao fisioterapeuta
```

### 3. Acompanhamento
```
Cliente executa → Você monitora
              → Ajusta programa
              → Reporta progresso
              → Recebe comissão
```
