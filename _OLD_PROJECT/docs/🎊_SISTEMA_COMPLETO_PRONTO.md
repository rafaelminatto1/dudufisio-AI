## 🚀 COMO USAR

### 1. Instalar Dependências
```bash
npm install
```

### 2. Configurar Variáveis de Ambiente
```bash
cp .env.example .env.local
# Editar .env.local com suas chaves
```

### 3. Rodar em Desenvolvimento
```bash
npm run dev
```

### 4. Acessar a Página
```
http://localhost:5173/acompanhamento/monitoramento
```

## 🤖 CONFIGURAÇÕES OPCIONAIS

### Gemini IA (Opcional)
```env
VITE_GEMINI_API_KEY=AIzaSy...
```
- **Sem chave:** Usa regras (rápido, gratuito)
- **Com chave:** Usa IA real (inteligente, pago)
- **Fallback automático** em caso de erro

### WhatsApp (Opcional)
```env
# Opção 1: Web (gratuito para dev/test)
VITE_WHATSAPP_USE_WEB_CLIENT=true

# Opção 2: Business API (necessário para produção)
VITE_WHATSAPP_PHONE_NUMBER_ID=...
VITE_WHATSAPP_ACCESS_TOKEN=...
```
