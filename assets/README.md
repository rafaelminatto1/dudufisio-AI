# Assets - Activity Fisioterapia

## Logo Activity Fisioterapia

Para gerar os ícones PWA, adicione o logo da Activity Fisioterapia neste diretório:

**Arquivo:** `logo-activity.png`

### Especificações:
- **Formato:** PNG
- **Fundo:** Transparente ou preto
- **Tamanho recomendado:** 512x512 ou maior
- **Qualidade:** Alta resolução

### Como usar:
1. Adicione o logo em `assets/logo-activity.png`
2. Execute: `npm run generate:icons:from-logo`
3. Os ícones serão gerados em `public/`

### Ícones gerados:
- `icon-192.png` (192x192) - Android home screen
- `icon-512.png` (512x512) - Android splash screen
- `apple-touch-icon.png` (180x180) - Apple Touch Icon
- `favicon-32.png` (32x32) - Favicon

---

**Nota:** O logo será usado com fundo preto (#000000) para garantir boa visibilidade em todos os dispositivos.
