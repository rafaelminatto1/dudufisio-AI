## 💻 **COMO USAR - FLUXO COMPLETO**

### **URL**: `http://localhost:5176/free-video-generator`

### **OPÇÃO 1: Criar Novo Exercício com Vídeo** ⭐

#### **Passo a Passo**:

1. **Acesse a página**
   ```
   http://localhost:5176/free-video-generator
   ```

2. **Configure o form**
   ```
   Ação: "Criar Novo Exercício com Vídeo"
   Nome: "Passagem de Guarda Fechada"
   Modalidade: Jiu-Jitsu
   Ferramenta: CapCut (recomendado)
   Dificuldade: Intermediário
   Grupos Musculares: Core, Pernas
   Contexto: "Demonstração em câmera lenta, 2 atletas"
   ```

3. **Clique "Gerar Guia"**
   ```
   → Sistema otimiza prompt para CapCut
   → Exibe guia passo a passo
   → Mostra prompt otimizado
   ```

4. **Copie o prompt e abra CapCut**
   ```
   → Botão "Copiar Prompt"
   → Botão "Abrir CapCut"
   → Cole o prompt no CapCut
   → Configure: 10s, 16:9, HD
   → Clique "Generate"
   ```

5. **Aguarde geração no CapCut** (1-2 min)
   ```
   → CapCut processa
   → Vídeo gerado
   → Baixe o vídeo (MP4)
   ```

6. **Upload no sistema**
   ```
   → Clique "Fazer Upload do Vídeo Gerado"
   → Arraste o arquivo baixado
   → Upload automático
   ```

7. **Exercício criado automaticamente!** 🎉
   ```
   ✅ Exercício "Passagem de Guarda Fechada" criado
   ✅ Vídeo vinculado automaticamente
   ✅ Disponível em /exercise-library
   ✅ Pode ser usado em protocolos
   ✅ Salvo na biblioteca de vídeos
   ```
