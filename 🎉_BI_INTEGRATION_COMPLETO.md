2. Clique **"Inicializar Sistema BI"**
3. Clique **"Executar Verificação"**
4. Veja os resultados!

### Modo Demo (sem Supabase)

1. Vá para aba **"Configuração"**
2. Ative **"Modo Demonstração"**
3. Todas as funcionalidades funcionam com dados simulados!

### Com Supabase Real

1. Configure `.env.local`:
   ```env
   VITE_SUPABASE_URL=sua_url
   VITE_SUPABASE_ANON_KEY=sua_chave
   ```
2. Reinicie o servidor
3. Use com dados reais!
