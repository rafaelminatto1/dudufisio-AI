# 🚀 Início Rápido - Sistema de Evolução de Sessão

## Em 3 Minutos Você Estará Usando!

---

## ⚡ Passo 1: Escolher Interface (1 min)

### Acesse as Configurações:
```
🔗 /session-evolution-settings
```

### Escolha seu modo favorito:

**🏠 Sistema Existente** (Recomendado para começar)
- Interface atual que já funciona
- Sem mudanças bruscas
- Ideal para primeiro uso

**📄 Página Nova** (Para casos complexos)
- 4 colunas com tudo visível
- Histórico, gráficos e objetivos juntos
- Visão completa do paciente

**🪟 Modal** (Para rapidez)
- Abre sobre a agenda
- Não perde contexto
- Atendimentos rápidos

**➕ Expansão** (Híbrido)
- Combina atual com novos recursos
- Transição suave

### Salvar:
```
Clique: "Salvar Configuração" ✅
```

---

## 🧪 Passo 2: Testar com Dados Mock (1 min)

### Popular Dados de Teste:

Na mesma página de configurações, role até:
**"Gerenciamento de Dados Mock"**

1. Digite no campo: `patient_1`
2. Clique: **"Popular Dados Mock"**
3. ✅ Pronto! Sistema criou:
   - 10 sessões de exemplo
   - 2 templates de conduta
   - Dados de evolução (dor, amplitude, etc)

---

## 🎯 Passo 3: Usar o Sistema (1 min)

### Iniciar Atendimento:

1. Vá em: **Agenda** (`/agenda`)
2. Clique em qualquer agendamento
3. Clique: **"Iniciar Atendimento"**
4. ✨ Sistema abre no modo que você escolheu!

---

## 🎨 O Que Você Verá

### Se escolheu "Página Nova" (4 colunas):

```
┌──────────┬──────────┬──────────┬──────────┐
│          │          │          │          │
│ SOAP     │HISTÓRICO │EVOLUÇÃO  │OBJETIVOS │
│          │          │          │          │
│Preencha  │Veja      │Veja      │Veja      │
│formulário│sessões   │gráficos  │metas com │
│          │anteriores│e alertas │countdown │
│          │          │          │          │
└──────────┴──────────┴──────────┴──────────┘
```

### Explore:

**Coluna 1 - Formulário:**
- Subjetivo, Objetivo, Avaliação, Plano
- Escala de dor (slider)
- Botão "Replicar Conduta"

**Coluna 2 - Histórico:**
- 📜 Sessões anteriores
- 🏥 Cirurgias (timeline)
- ⏱️ Tempo de tratamento

**Coluna 3 - Evolução:**
- ⚠️ Alertas de testes obrigatórios
- 📊 Gráficos de evolução (3 tipos)
- 📋 Tabela (export CSV)
- 🏥 Patologias ativas/tratadas

**Coluna 4 - Objetivos:**
- 🎯 Objetivos com countdown
- 📊 Métricas rápidas
- 📞 Contato rápido

---

## 💡 Recursos Rápidos

### Replicar Conduta Anterior:
```
Botão "Replicar Anterior"
→ Copia tudo da última sessão
```

### Ver Gráfico de Evolução:
```
Coluna 3 → Selecionar métrica → Gráfico aparece
Alterne: Barras | Linha | Área
```

### Gerar Insights para Laudo:
```
Insights automáticos aparecem
Botão "Copiar" → Cola no laudo
```

### Adicionar Objetivo com Countdown:
```
Coluna 4 → "+" → Preencher → Salvar
Countdown animado aparece!
```

## ⚙️ Configurações Úteis

### Ver Qual Fonte de Dados Está Usando:
```
Olhe no canto inferior direito:
🟢 Supabase = dados reais
🟡 Mock = dados de teste
```

### Limpar Dados de Teste:
```
/session-evolution-settings
→ Rolar até "Gerenciamento"
→ "Limpar Todos os Mocks"
→ Confirmar 2x
```

### Trocar de Modo:
```
/session-evolution-settings
→ Clicar em outro modo
→ Salvar
→ Próximo atendimento já usa o novo modo!
```

## 🎯 Fluxo Completo de Uso

### 1. Configurar (primeira vez)
```
Escolher modo → Salvar → Popular mocks (opcional)
```

### 2. Uso Diário
```
Agenda → Agendamento → "Iniciar Atendimento"
→ Sistema abre
→ Preencher SOAP
→ Ver contexto nas outras colunas
→ Salvar
```

### 3. Ver Evolução do Paciente
```
Coluna 3 → Selecionar métrica
→ Ver gráfico de evolução
→ Alternar tipo de gráfico
→ Export CSV se precisar
```

### 4. Definir Objetivos
```
Coluna 4 → "+" Adicionar
→ "Prova TAF - 1km em 2min"
→ Data: 20/03/2025
→ Salvar
→ Countdown aparece automaticamente!
```

### 5. Gerar Laudo Médico
```
Insights aparecem automaticamente
→ "Redução de dor de 9/10 para 0/10"
→ Clicar "Copiar"
→ Colar no laudo
```

## 🆘 Ajuda Rápida
