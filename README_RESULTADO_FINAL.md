## 📝 COMO USAR

### Modo Escuro/Claro
1. Vá para Agenda
2. Clique no botão "Tema" na toolbar
3. Escolha: Claro, Escuro ou Sistema

### Exportar Agenda
1. Na Agenda, clique no menu "⋮"
2. Selecione "Exportar Agenda"
3. Escolha o formato desejado

### Comparar Terapeutas
1. Na Agenda, clique no menu "⋮"
2. Selecione "Comparar Terapeutas"
3. Veja gráficos e rankings
