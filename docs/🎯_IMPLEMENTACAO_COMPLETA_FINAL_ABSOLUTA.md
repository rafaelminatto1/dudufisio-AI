## 🔍 TROUBLESHOOTING

### Se o sistema não carregar:

1. **Limpar Cache:**
```bash
Remove-Item -Recurse -Force node_modules\.vite
npm run dev
```

2. **Verificar Console:**
- Abrir DevTools (F12)
- Ver erros no console
- Verificar se há erro de Context

3. **Hard Reload:**
- Ctrl+Shift+R (Windows)
- Limpar localStorage

4. **Verificar Providers:**
- AppRoutes.tsx deve ter ExerciseProvider
- Hierarquia correta de Contexts
