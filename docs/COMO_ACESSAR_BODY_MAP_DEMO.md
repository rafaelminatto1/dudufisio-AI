# 🔐 COMO ACESSAR O BODY MAP DEMO - PASSO A PASSO

**Problema:** O link direto não funciona porque precisa fazer login primeiro.

**Solução:** Siga os passos abaixo! ⬇️

---

## ✅ MÉTODO 1: CLIQUE NO MENU (MAIS FÁCIL!) ⭐⭐⭐

### **Passo 1: Fazer Login**
1. Abra o navegador (Chrome, Firefox, Edge)
2. Digite na barra de endereços:
   ```
   http://localhost:5176/
   ```
3. Pressione `Enter`
4. **Faça login** com seu usuário e senha
5. Aguarde carregar o dashboard

### **Passo 2: Clicar no Menu**
1. Olhe para o **menu lateral esquerdo**
2. Procure a seção **"Ferramentas IA"**
3. Clique em **"🎨 Body Map NOVO"** ✨
4. **Pronto!** A página vai abrir automaticamente!

---

## ✅ MÉTODO 2: LOGIN + NAVEGAÇÃO MANUAL

### **Passo 1: Fazer Login**
1. Abra o navegador (Chrome, Firefox, Edge)
2. Digite na barra de endereços:
   ```
   http://localhost:5176/
   ```
3. Pressione `Enter`
4. **Faça login** com seu usuário e senha
5. Aguarde carregar o dashboard

### **Passo 2: Navegar para a Demo**
**APÓS FAZER LOGIN**, digite na barra de endereços:
```
http://localhost:5176/body-map-demo
```
E pressione `Enter`.

✅ **Pronto!** Você deve ver a página do Body Map Demo!

---

## ✅ MÉTODO 2: USANDO O CONSOLE DO NAVEGADOR

Se o Método 1 não funcionar, tente este:

### **Passo 1: Fazer Login**
1. Abra: `http://localhost:5176/`
2. Faça login
3. Aguarde estar no dashboard

### **Passo 2: Abrir DevTools**
1. Pressione `F12` (ou `Ctrl+Shift+I`)
2. Clique na aba **"Console"**

### **Passo 3: Executar Comando**
Cole este código no console e pressione `Enter`:
```javascript
window.location.href = '/body-map-demo';
```

✅ **Pronto!** A página vai carregar automaticamente!

## 🐛 SE AINDA NÃO FUNCIONAR

### **Erro: "Cannot GET /body-map-demo"**
- ✅ Certifique-se que fez login ANTES
- ✅ Verifique se o servidor está rodando (`npm run dev`)
- ✅ Tente fechar e abrir o navegador

### **Erro: Volta para login**
- ✅ Certifique-se que fez login com credenciais válidas
- ✅ Aguarde o dashboard carregar completamente
- ✅ Então navegue para `/body-map-demo`

### **Erro: Página em branco**
- ✅ Abra o console (F12) e veja se há erros
- ✅ Copie os erros e me envie
- ✅ Tente dar refresh (F5)
