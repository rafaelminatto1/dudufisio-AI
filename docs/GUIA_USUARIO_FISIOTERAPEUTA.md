## 🚀 Fluxos de Trabalho

### 1. Atendimento Completo
```
1. Verificar agenda do dia (/therapist-dashboard)
2. Clicar no paciente agendado
3. Abrir atendimento (/atendimento/:id)
4. Preencher evolução
5. Registrar procedimentos
6. Consumir insumos utilizados
7. Gerar laudo (opcional, com IA)
8. Finalizar atendimento
9. Paciente recebe resumo por email
```

### 2. Prescrever Exercícios (HEP)
```
1. Ir para /gerar-hep
2. Selecionar paciente
3. Informar diagnóstico e objetivos
4. IA sugere exercícios personalizados
5. Revisar e ajustar sugestões
6. Gerar PDF do programa
7. Enviar para paciente
8. Paciente vê em "Meus Exercícios"
```

### 3. Gerar Laudo de Avaliação
```
1. Ir para /gerar-laudo
2. Preencher dados de avaliação
3. IA gera laudo estruturado
4. Revisar e editar se necessário
5. Salvar no prontuário
6. Exportar PDF
7. Enviar para paciente/convênio
```
