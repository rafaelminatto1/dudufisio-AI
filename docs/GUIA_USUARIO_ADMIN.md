## 🚀 Fluxos Principais

### 1. Adicionar Novo Paciente
1. Ir para `/patients`
2. Clicar em "Novo Paciente"
3. Preencher formulário
4. Salvar
5. Paciente aparece na lista

### 2. Criar Agendamento
1. Ir para `/agenda`
2. Clicar em slot livre
3. Selecionar paciente
4. Definir terapeuta
5. Confirmar agendamento
6. Paciente recebe notificação

### 3. Gerar Relatório
1. Ir para `/reports`
2. Selecionar tipo de relatório
3. Definir período
4. Aplicar filtros
5. Gerar relatório
6. Exportar ou visualizar

### 4. Gerenciar Usuários
1. Ir para `/users`
2. Clicar em "Novo Usuário"
3. Preencher dados
4. Definir role e permissões
5. Salvar
6. Usuário pode fazer login

## 💡 Dicas e Truques

### Atalhos de Teclado
- `Ctrl/Cmd + K` - Busca global (quando implementado)
- `ESC` - Fechar modais
- `Tab` - Navegar entre campos de formulário

Use o menu lateral para acesso rápido às páginas principais.

### Exportação de Dados
Todos os relatórios podem ser exportados em PDF ou Excel.

### Notificações
Fique atento ao ícone de sino no header - mostra notificações importantes.
