## 🚀 QUICK START (30 MIN)

### 1. Configurar Supabase (5 min)

```
1. Criar projeto em https://app.supabase.com
2. Copiar URL e anon key
```

### 2. Configurar .env.local (2 min)

```env
VITE_SUPABASE_URL=https://seu-projeto.supabase.co
VITE_SUPABASE_ANON_KEY=sua_chave_anon
```

### 3. Aplicar Migrations (15 min)

```
Via Supabase Dashboard > SQL Editor:
Aplicar 16 migrations em ordem cronológica
```

### 4. Seed & Run (3 min)

```bash
npm install
npm run seed
npm run dev
```

### 5. Abrir Sistema (1 min)

```
http://localhost:5173
```

**Guia Detalhado:** `🚀_QUICK_START_PROXIMA_SESSAO.md`
