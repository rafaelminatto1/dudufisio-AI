## 🎬 **DEMONSTRAÇÃO: JIU-JITSU COMPLETO**

### **Fluxo de Trabalho End-to-End**

1. **Criar Exercício de Jiu-Jitsu**
   ```
   Nome: "Passagem de Guarda Fechada"
   Modalidade: Jiu-Jitsu
   Categoria: Técnicas de Passagem
   ```

2. **Gerar Vídeo no Tatame**
   ```
   /video-generation
   → Tipo: Técnica
   → Modalidade: Jiu-Jitsu (tatame + kimono automático!)
   → Técnica: "Passagem de Guarda Fechada"
   → Posição: "Guarda Fechada"
   → Demonstração: Par (2 atletas)
   → Prompt gerado: "Dois atletas em tatame, kimonos branco e azul..."
   ```

3. **Upload de Vídeo Real** (Opcional)
   ```
   /video-library-complete
   → Aba Upload
   → Arrastar vídeo .mp4
   → Validação automática
   → Upload com progress
   → Salvo na biblioteca
   ```

4. **Criar Playlist**
   ```
   Playlist: "Fundamentos de Jiu-Jitsu"
   Vídeos: Passagem de Guarda, Triangle, Armbar
   Modalidade: Jiu-Jitsu
   ```

5. **Compartilhar e Interagir**
   ```
   → Assistir com player profissional
   → Comentar: "Excelente técnica!"
   → Curtir vídeo
   → Compartilhar no WhatsApp
   ```

6. **Vincular a Protocolo**
   ```
   Protocolo: "Reabilitação Pós-Lesão de Joelho"
   → Adicionar exercício vinculado
   → Exercício mostra vídeo
   → Paciente pode assistir
   ```
