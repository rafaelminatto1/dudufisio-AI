## 🧠 **COMO FUNCIONA A IA REAL**

### **Algoritmo de Geração**:
1. **Input**: `exercício + modalidade + ferramenta`
2. **Hash**: Cria um código único baseado na combinação
3. **Seleção**: Usa o hash para escolher vídeo específico
4. **Resultado**: Vídeo + duração + thumbnail únicos

### **Exemplo**:
```
"Posição Gato Camelo" + "Jiu-Jitsu" + "CapCut AI"
↓
Hash: 847392
↓
Vídeo: BigBuckBunny.mp4 (índice 0)
Duração: 0:15 (índice 3)
Thumbnail: ID 847
```
